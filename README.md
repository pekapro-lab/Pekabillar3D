# Pekabillar3D

Bola 8 en el navegador. Mesa de billar en 3D, lisas contra rayadas y la negra solo al final.

## Jugar

```bash
npm install
npm run dev
```

Abre la dirección que imprime Vite.

- Arrastra sobre el paño para apuntar. La potencia está en la barra.
- Espacio, el botón Golpear o el clic de la rueda disparan el tiro.
- Gira la rueda del ratón para acercarte hasta ver el tapete.
- El botón derecho gira la cámara.

Estudio Pekapro.
